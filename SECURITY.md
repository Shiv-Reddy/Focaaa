# Security reports

Please send a private report to [xlr8beast2h@gmail.com](mailto:xlr8beast2h@gmail.com) with the affected version, steps to reproduce using disposable data, and the expected impact.

Do not open a public issue containing a PIN, recovery key, invite code, message content, Firebase credential, signing key, or device token. This early-access build has not had an independent security audit. The published [privacy notice](https://focaaa-download.focaaa-free-relay.workers.dev/privacy.html) explains current data handling and limits.
